# Errores y propuestas de cambio

Puede comunicar errores o proponer mejoras mediante las [incidencias de MicroGrano](https://github.com/Sajaus01/MicroGrano/issues). Describa qué intentaba hacer, qué ocurrió y qué resultado esperaba. Indique la versión de MicroGrano, Python y el sistema operativo, junto con los pasos mínimos para reproducir el problema. Si afecta a la interfaz, identifique el paso del asistente y los controles utilizados; si afecta a la biblioteca, incluya la función y sus parámetros.

Utilice datos sintéticos o un ejemplo mínimo que pueda compartir. Antes de adjuntar un registro, una sesión o una captura, retire credenciales, datos personales, rutas privadas y contenido de terceros. Las sesiones pueden contener las imágenes importadas. No publique micrografías privadas para demostrar un error.

## Cambios de código o documentación

Una propuesta de cambio debe explicar el problema, la modificación y cómo se comprobó. Para cambios de comportamiento, incluya una prueba que reproduzca el error o compruebe el resultado esperado. Mantenga la implementación científica en la biblioteca y conserve la compatibilidad de sus contratos con el asistente. No presente una comprobación con datos sintéticos como validación metalográfica.

Las instrucciones de instalación y ejecución de pruebas están en [README.md](README.md). Indique qué pruebas ejecutó y su resultado; la existencia de una configuración de GitHub Actions no sustituye ese registro.
