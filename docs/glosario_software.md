# Términos de software de esta entrega

Se mantiene «límite de grano» para la entidad metalográfica; un contorno o una transición de intensidad no recibe esa identidad por el solo resultado del algoritmo. Estos términos de soporte complementan la documentación del repositorio, sin modificar el glosario editorial.

| Término | Uso en MicroGrano |
|---|---|
| API, interfaz de programación | Funciones y contratos accesibles desde Python |
| Región de interés (ROI) | Dominio de análisis con origen, límites y revisión de anotaciones |
| Máscara | Arreglo booleano que selecciona píxeles de primer plano |
| Clase de intensidad | Identificador computacional de un grupo de intensidades, no una fase física |
| Instancia | Objeto individual con identificador; no prueba por sí misma que sea un grano |
| Etiqueta de objeto | Entero positivo que identifica una instancia; cero representa fondo |
| Marcador | Semilla identificada para dirigir una separación mediante watershed |
| Artefacto de sesión | Arreglo almacenado y sus metadatos; no debe confundirse con un artefacto de preparación metalográfica |
| Marco de la ROI | Límite del dominio recortado para aplicar reglas de inclusión/exclusión |
| Grafo de operaciones | Registro de relaciones entre entradas, parámetros y salidas; admite ramas alternativas |
| Reproducción computacional | Reejecución de las llamadas registradas y comparación con las salidas guardadas |
| SHA-256 | Suma de comprobación para detectar modificaciones de los archivos |
| Prueba automatizada | Caso programado que verifica una propiedad esperada del software |
| Bootstrap | Remuestreo con reemplazo; su unidad debe corresponder al diseño del estudio |
| Watershed | Separación por inundación de una topografía computacional guiada por marcadores |
| PSNR y SSIM | Medidas respecto de una referencia conocida; no sustituyen validación metalográfica |
| Ppp | Puntos por pulgada de la figura exportada, distintos de la resolución óptica |
