# Conjunto sintético

Estos archivos se generan mediante `micrograno.sinteticos.guardar_conjunto`. Son figuras numéricas artificiales y seis valores convencionales por campo para probar todas las funciones, no micrografías, mediciones de una probeta ni resultados del libro.

La escala de 0.5 µm/px es únicamente una convención de prueba. Los NPY conservan las matrices exactas; los PNG/TIF permiten comprobar la importación gráfica. Las etiquetas de objetos, las clases de intensidad, los límites y los marcadores son entradas diferentes. El CSV tiene separador coma y punto decimal.

El generador y la ficha `procedencia.json` permiten reconocer y reproducir el origen de estos datos. Este directorio contiene exclusivamente datos artificiales; las micrografías propias del autor se entregan en el paquete separado del experimento.
